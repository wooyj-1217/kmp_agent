# 남은 미결정 사항

목표·책임 경계는 [프로젝트 목표](project-goal.md)를 따른다. 공통 규격·역할·작업·버전·가정/질문 계약과 현재 구현은 관련 문서에 유지한다. 제품 선택·실험 목표치를 하네스 전체의 미결정이나 착수 차단 조건으로 두지 않는다.

## 공통 하네스의 남은 결정

| ID | 항목 | 남은 결정·현재 경계 |
| --- | --- | --- |
| D2 | 전체 실행 연결·권한 | 적용 프로젝트의 실행/테스트 명령 인터페이스, 모델/도구 어댑터, 자동 수정·반환·재검증 권한과 차단 조건. 명시적 역할 실행과 근거 검사는 구현됐지만 전체 제품 실행은 PLANNED |
| D3 | 상태·예산·복구 확장 | 기존 상태·잠금·시도 상한·checkpoint 실행 재개를 재사용. 자동 재시도·전체 복구·시간/토큰/비용 한도·일반 YAML 지원은 남음. 코드 복원은 현재 보장하지 않음 |
| D4 | 프로젝트별 기록 보관 | 원문·근거의 보관 기간·마스킹 범위와 설정. 제품 기록/문제의 원본 자동 전송은 하지 않는 경계로 확정. 기존 개발용 연결 점검이 저장하는 진단 메타데이터의 최소 범위·보관 위치/기간은 별도 정리 필요 |
| D5 | 추적·환경 식별 보완 | 하네스 배포 버전과 피처/제품 릴리스 구분, Git·SHA·artifact·P/D·CR 재사용은 확정. 추가 어댑터/평가 정의 해시 범위와 환경 고정 세부는 남음. 새 개발 번호 체계는 요구하지 않음 |
| D6 | 사용량 수집 | 제공 필드·비용 출처·가격표 관리·시간 측정 경계·미귀속 처리 |
| D7 | 평가 지원 인터페이스 | 공통 지표의 근거/집계 연결·누락 처리·비교 프로토콜. 구체적 시나리오·목표치·분모·관측 구간·채택 임계값은 적용 프로젝트가 정하며 자동 집계기는 PLANNED |
| D9 | 선택 도구 연결 | 기획·디자인·브라우저 등 어댑터와 선택 방식. HTML/CSS 시안 규격은 유지하며 특정 유료 서비스·요금제는 공통 필수 의존성이 아님 |
| D10 | 감시·변경 확정 설정 | 감시할 원본/경로·변경 확정 조건을 프로젝트가 정하는 실행 스키마와 중복/동시 변경 처리. 현재 project-settings.json에는 이 감시 계약이 없음 |
| D11 | 변경 자동 대응 | 기획/디자인 변경의 의미상 영향 분석·기준 갱신·관련 구현 수정·재검증·실패 반환/복구 실행. 기존 CR/Git/snapshot/검증 상태를 재사용할 설계와 미확정·영향 미상 처리; 전체 자동화는 PLANNED |

## 하네스 결함 개선 PR의 후속 구현

[개선 PR 정책](harness-defect-pr.md)으로 네 가지 분류, 설정 우선 조사, 최소 재현·원본 격리 수정·검증·Draft PR까지의 자동 수행 권한, 머지/정식 배포의 사용자 승인은 확정했다. 권한 부족 시 로컬 초안·차단 사유, 설치 사본 직접 수정을 정식 해결로 삼지 않기, 영향 작업만 차단·수정 버전 검증 후 재개도 정책이다.

미정/미구현은 정책 적용·원격/격리 작업 공간·프로젝트 업데이트 정책의 설정 인터페이스, 자동 분류·제품 정보 제외/재현·수정/검증 실행, Draft PR URL 역연결, 머지/배포 승인 집행, 저장소 간 문제/실행/해결 버전 참조 검사와 재개 자동화다. 기존 task/agent_run·artifact·CR·Git·검증 상태를 재사용하며 새 enum/버전/DB를 현재 지원으로 가정하지 않는다. 이번 문서 수정은 실제 PR/배포를 수행하지 않는다.

## 적용 프로젝트에서 결정하는 사항

- D1 제품 목표·범위: 실제 문제·사용자·MVP·기능·정책·기획/디자인 원본·인수 조건.
- D8 제품 스택·환경: 기술·플랫폼·라이브러리·DI·아키텍처·실행/테스트 명령. Ktor/KMP는 선택적 참조다.
- 감시 대상·변경 확정 조건, 실험 시나리오·목표치·관측 범위.
- 기능별 담당·공유 코드/API 계약·저장소/PR·검증 항목과 프로젝트의 도구/서비스 선택.

D1/D8은 과거 참조를 유지하기 위한 ID이며 특정 첫 제품을 하네스에서 선정하라는 작업 지시가 아니다. 각 결정과 UNKNOWN의 단계별 영향·변경 근거·피처 기준·관련 작업은 해당 프로젝트에서 보관한다.
