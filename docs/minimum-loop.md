# 최소 실행 루프 현황

이 문서는 기존 참조를 위한 안내다. 단계·완료 상태를 별도로 관리하지 않는다.

- 목적·구조·구현 상태: [공통 하네스 설계](../design.md).
- 완료된 기반·첫 제품의 단계/의존성/완료 기준·평가 계획: [실행 계획](../plan.md).
- 작업 상태·역할 실행·검토·인계: [작업 관리](task-management.md).
- 판단·버전·검증 완료 기준: [운영 설계](operations.md).
- 중단 후 근거 보완·완료 단계 보존·시간 분류: [중단·재개](interruption-recovery.md).

과거 문서 인계 시험은 필요할 때 실행 계획의 근거 링크로 확인한다. 일반 제품 작업 전에 예제·실험 기록을 모두 읽을 필요는 없다.
