# v0.4.8 — 선택 UI 미응답 시 네이티브 텍스트 승인 복구

v0.4.7 이후 PR #27을 포함한 패치 릴리스입니다. 선택 UI가 실제 응답을 만들지 못할 때도 전체 동결 질문에 연결된 정확한 선택지 텍스트를 검증하고, 이미 받은 원문은 공식 복구 경로로 재검증할 수 있습니다. 최종 배포 SHA·원격 검증 결과는 게시 본문에서 확정합니다.

## v0.4.7 대비 변경

- 질문 도구의 `accepted:true`와 사용자 선택을 구분합니다. 실제 질문과 인접 native 사용자 입력에 연결된 정확한 라벨 하나만 허용하며 단일 불릿을 지원합니다.
- `question-status`의 전체 `text_fallback_prompt`를 일반 텍스트로 표시해 UI 없이 선택을 받을 수 있습니다. pinned UI 질문의 제약은 명시합니다.
- 기존 `answer-question`·`recover-question`을 재사용합니다. 범위·파일·출처·canonical ID를 유지하고 전송 근거를 `text_prompt`로 따로 남깁니다.
- 다른 질문·실행에 대한 모호한 응답, 일반 진행 요청·인용·중복·상충을 거절하고 소비 시 현재 원문 끝까지 재검사합니다.

명령은 수동 호출하며 명령 내부에서 계약을 검사합니다. 잘못된 기존 ID를 자동 변경하지 않으며 제품을 자동 승인·업데이트·재개하지 않습니다. UI 클릭 실패 자체의 내부 원인 해결을 뜻하지 않습니다.

## 설치·업데이트

신규 설치는 게시된 v0.4.8 bootstrap을 명시 선택합니다. 임시 경로와 제품 Git 루트는 실제 사용할 경로로 바꾸세요.

```sh
rtk proxy git clone --depth 1 --branch v0.4.8 git@github.com:wooyj-1217/kmp_agent.git /tmp/kmp-agent-bootstrap
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py install --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.8 --target /path/to/product
```

v0.4.3~v0.4.7 설치본의 프로젝트 루트에서는 다음 단일 명령을 사용합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.8
```

기존 source를 사용하므로 다른 셸 명령·`--source`·`--target`을 덧붙이지 않습니다. v0.4.2 이하는 사용자 터미널의 새 bootstrap으로 전환합니다. 선택 SHA·runtime과 새 세션의 훅 신뢰·활성을 확인하세요. 기존 원장·선택지는 자동 이전하지 않습니다. 이미 유효한 원문이 있으면 수정 버전에서 기존 질문·범위와 함께 공식 복구를 재검증하며 다시 선택할 필요가 없습니다. 실제 제품 설치·승인 복구·재개는 별도입니다.

[0.4.8 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.8/docs/installation.md)

## 검증 범위와 알려진 제한

동일 구현의 PR clean checkout 관련 **150개 PASS**, 독립 보안 검토 **40개 PASS**와 설치 패키징 검사를 확인했습니다. 실제 기존 원문을 변경하지 않고 메모리 원장 복사본에서 공식 복구·대체 체인·멱등을 검증했으며 실제 제품 원장과 native 파일은 변경하지 않았습니다. 최종 후보·원격 태그 신규 설치/재설치·v0.4.7 업데이트 결과는 게시 본문에서 확정합니다.

실제 설치본 훅·전체 모델 E2E·공통 예제·실제 제품 업데이트/승인 복구/인수는 NOT_RUN입니다. UI 클릭 실패·Chrome 시작 실패·RESTART_REQUIRED 내부 원인은 UNKNOWN이며 이번 변경으로 해결됐다고 주장하지 않습니다. 개인 원문·제품 자료·검증 로그는 공개하지 않습니다.
