# 미배포 변경

## v0.4.8 선택 UI 미응답 시 동결 질문의 네이티브 텍스트 선택

v0.4.7은 UI 표시 요청만 접수되고 구조화 응답이 없는 경우 typed 승인을 연결하지 못했다. 전체 동결 질문·선택지를 실제로 제시한 native 원문과 직접 응답한 정확한 선택지 라벨을 검증하는 대체 전송을 추가한다. question-status는 UI 없이 제시할 전체 텍스트를 제공하고 원래 answer-question/recover-question을 사용한다. 일반 진행 요청·인용·모호한 선택·중복·상충은 거절하며 승인 범위·원문·현재 bytes와 canonical ID 검사를 유지한다. 실제 제품 원장·선택지 ID를 자동 변경하지 않는다. [계약·사용 절차](../approval-authority.md#선택-ui가-응답하지-않을-때의-네이티브-텍스트-선택)를 따른다. 이 변경은 [v0.4.8 지원 범위](v0.4.8.md)와 [본문 원본](v0.4.8-notes.md)에 연결하며 최종 SHA·원격 검증·게시 결과는 해당 Release에서 확인한다. v0.4.7 태그·기존 설치본·제품 원장은 변경하지 않는다. UI 클릭 실패 자체의 내부 원인을 해결했다고 주장하지 않는다.

## v0.4.7 네이티브 승인 응답과 감사 가능한 복구

UI 응답의 질문 문자열이 줄바꿈 정규화·UTF-8 512바이트 절단으로 바뀌어도 실제 호출 ID·질문 항목·전체 질문·선택지·동결 계약에 연결해 검증한다. typed 질문은 등록 단계에서 canonical `approve` ID를 검사한다. `recover-question`은 기존 원문·당시 범위와 현재 파일을 재검증하고 감사 이력을 남기며 답변·선택지 ID를 바꾸지 않는다. 잘못 등록한 구버전 ID는 원문 복구와 승인 소비 불가를 구분한다. 제품 cwd guard는 유지하고 원본 checkout의 별도 세션으로 넘기는 위치·자료를 안내한다.

변경은 [v0.4.7 지원 범위](v0.4.7.md)와 [본문 원본](v0.4.7-notes.md)에 연결한다. 최종 SHA·원격 검증·게시 결과는 해당 GitHub Release에서 확인하며 v0.4.6 태그·설치본과 실제 제품 원장은 변경하지 않는다. 합성 회귀와 실제 Codex UI 시험을 구분하고, 임시 시험 승인을 제품 권한으로 사용하지 않는다. Chrome 시작 실패·RESTART_REQUIRED는 원인이 미확인인 별도 항목이다.

## v0.4.6 제품 준비·추가 단계 연결 보완

실제 훅의 `collaborationspawn_agent`·`webrun` 이름을 정확한 조회/검토 별칭으로 지원하고, 제한된 세션 진단 argv를 추가한다. 공식 task CLI로 신규·기존 미착수 단계를 전체 계획에 명시 추가할 수 있다. 같은 프로젝트·작업 종류, 변경 근거·원자성·타 계획 소속 검사를 유지한다. design documentation의 정확한 HTML/CSS 시안 경로와 루트 project-settings.json 초안 등록, 준비 순서별 복구 안내를 보완한다. 제품 구현·원본 승인·ready/begin 조건은 유지한다.

이 항목은 [v0.4.6 지원 범위](v0.4.6.md)와 [본문 원본](v0.4.6-notes.md)에 연결했다. 실제 게시·최종 SHA·원격 검증은 해당 Release에서 확정하며 v0.4.5 태그·설치본을 바꾸지 않는다. 합성 guard·설치 CLI 회귀와 실제 모델/제품 재개를 구분한다. OS 샌드박스의 app-server 초기화 실패는 별도 환경 문제이며 이 수정으로 해결됐다고 주장하지 않는다.

v0.4.2 이후 관리 update 수정은 [v0.4.3 지원 범위](v0.4.3.md)에 연결했다. 기존 v0.4.2 guard에서의 최초 전환은 사용자 터미널 새 bootstrap이 필요하며, v0.4.3 설치 후 다음 명시적 update부터 지원 관리 경로를 사용한다. 최종 SHA·검증·게시 결과는 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.3)에서 확정한다. 이후 변경은 이 문서에 기록한다. 과거 배포 설명·검증 원본은 보존한다.

## v0.4.4

PR #18(`5d573db`)의 guard 저장·공유·종료·독립 검증 경계 변경을 [v0.4.4 지원 범위](v0.4.4.md)와 [Release 본문 원본](v0.4.4-notes.md)에 연결한다. VERSION은 0.4.4이며 최종 SHA·원격 검증·게시 결과는 해당 GitHub Release에서 확정한다. 기존 v0.4.3 배포 기록과 로컬 검증 원본은 보존한다.

## v0.4.5

현재 설치된 v0.4.4에서 압축 원문 조회 도구를 UI 검증으로 잘못 분류하고 공식 `--help`를 미분류 실행으로 막던 준비·조회 결함을 수정한다. 설치 프로젝트의 task 진입점과 `docs/guard-inputs/` 예시도 실제 허용 경로에 맞춘다. 계약 없는 제품 소스 구현 차단은 유지한다. 이 변경은 [v0.4.5 지원 범위](v0.4.5.md)와 [본문 원본](v0.4.5-notes.md)에 연결한다. 실제 게시 여부·최종 SHA·원격 검증은 해당 Release에서 확인하며 기존 v0.4.4 태그·설치본은 변경하지 않는다. 실제 Codex 훅·headroom 서비스 전달과 수정 버전의 실제 제품 적용 검증은 별도다.

## v0.4.6 초기 호출 안내 보완

첫 호출에서 복합 셸과 headroom `id` 인자를 잘못 사용해 거부되는 시행착오를 줄이도록 프로젝트/공통 AGENTS의 초기 안내와 오류의 재시도 예시를 보완한다. 단일 명령·hash-only 검사와 기존 보호 조건은 유지한다. 이 변경은 위 v0.4.6에 포함하며 v0.4.5 태그·Release·기존 설치본을 바꾸지 않는다.
