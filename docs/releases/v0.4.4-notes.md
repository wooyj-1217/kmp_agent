# v0.4.4 — 작업 저장·공유·종료와 제품 인증 분리

릴리스 준비 초안이다. 태그·Release는 아직 게시하지 않았으며 최종 배포 SHA와 원격 태그 검증을 게시 전에 확정한다.

## 이번 버전 요약

미완료 제품 작업의 문서 저장·체크포인트 commit·개발 브랜치 push·차단 보고가 제품 전체 완료를 요구하던 guard 경계를 수정합니다. 소스 구현과 공식 완료 검사는 유지하면서 독립 QA와 별도 검토 경로를 지원합니다.

## v0.4.3 대비 변경

- 저장용 add/commit과 개발 브랜치 공유를 허용합니다. 공유 push는 `--no-follow-tags`를 요구하고 태그·보호 ref·force·삭제·mirror는 거부합니다.
- Stop은 대화 턴을 종료합니다. finish는 `completed` 인증과 차단·인계·사용자 중단·일시정지 실행 종료를 구분합니다.
- 실제 collaboration 도구 이름과 독립 QA/review의 승인 명령을 지원합니다. 세션·계획·actor·현재 대상·argv 계약은 계속 검사합니다.
- 구조화 UI 도구의 정확한 대상·입력을 동결하고 화면/입력 action 및 검증 출력 경로로 제한합니다. CUA JS REPL의 클릭·입력은 지원하지 않습니다.
- 정상 검색 인자와 셸 연산자를 구분하고 안전한 조회·손상 원장 진단을 지원합니다. 문서 편집은 확장자 예외에서 사전 동결 경로로 전환합니다.

[0.4.4 지원 현황](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.4/docs/releases/v0.4.4.md)

## 설치·업데이트

게시 후 새 v0.4.4 bootstrap으로 신규 설치합니다. v0.4.3 설치본은 다음 명시적 관리 명령으로 전환합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.4
```

v0.4.2 이하의 첫 전환은 사용자 터미널에서 새 bootstrap을 사용하세요. 훅을 끄거나 설치 사본을 편집해 전환하지 않습니다. 새 세션·훅 신뢰/활성 상태는 설치 결과에 따라 별도로 확인합니다. 기존 documentation 작업은 필요한 경로를 동결한 새 작업으로 인계하고 공유 명령에 새 옵션을 반영합니다. 제품 파일·로그·과거 실행은 자동 변경하지 않습니다.

[0.4.4 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.4/docs/installation.md)

## 검증 범위

동일 구현 코드의 clean checkout 전체 877개와 영향 검사 121개 PASS를 구현 파일에 한정해 재사용합니다. 후보의 버전·설치·관리 update·guard 관련 121개 검사 PASS를 추가 확인했으며 최종 SHA·원격 태그 검증 결과는 게시 본문에서 확정합니다. 실제 Codex 훅 활성화·UI 연결·실제 적용 프로젝트·실제 모델 전체 E2E는 NOT_RUN입니다. 공식 완료 인증은 보호 권한 부재로 BLOCKED이며 테스트 PASS와 다릅니다.
