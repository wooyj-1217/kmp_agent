# v0.4.7 — 네이티브 승인 응답 인증·감사 복구 보완

v0.4.6 이후 PR #25를 포함한 패치 릴리스입니다. UI에서 질문이 정규화·절단돼도 실제 전체 호출과 승인 범위를 검증하며, 이미 받은 원문 응답을 감사 가능한 공식 경로로 복구할 수 있습니다. 최종 배포 SHA·원격 검증 결과는 게시 본문에서 확정합니다.

## v0.4.6 대비 변경

- UI 질문의 줄바꿈 정규화·UTF-8 512바이트 절단을 지원하고 네이티브 호출·전체 질문·선택지·동결 계약을 인증합니다.
- batch 항목을 각각 검증하며 같은 질문의 중복·상충 응답은 승인 소비 시점에도 차단합니다.
- typed 승인 질문은 등록 시 `approve` ID를 요구합니다. 기존 비표준 ID를 승인 권한으로 바꾸지 않습니다.
- `task --operation recover-question`은 정확한 원문 locator/hash와 당시 계약·현재 범위를 재검증하고 성공·거절 감사를 남깁니다. 실패 시 기존 답변을 보존하며 반복 복구도 재검증합니다.
- 제품 cwd 보호를 유지하고 하네스 수정을 별도 원본 세션으로 인계하는 방법을 안내합니다.

질문·복구 명령은 수동 호출하며 명령 내부에서 계약을 검사합니다. 답변 복구는 제품 구현 승인이나 잘못된 기존 질문의 자동 이전을 뜻하지 않습니다.

## 설치·업데이트

신규 설치는 게시된 v0.4.7 bootstrap을 명시 선택합니다. 아래 임시 경로와 제품 Git 루트는 실제 사용할 경로로 바꾸세요.

```sh
rtk proxy git clone --depth 1 --branch v0.4.7 git@github.com:wooyj-1217/kmp_agent.git /tmp/kmp-agent-bootstrap
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py install --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.7 --target /path/to/product
```

v0.4.3~v0.4.6 설치본의 프로젝트 루트에서는 다음 단일 명령을 사용합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.7
```

기존 source를 사용하므로 `--source`·`--target`이나 다른 셸 명령을 덧붙이지 않습니다. v0.4.2 이하는 사용자 터미널의 새 bootstrap으로 전환합니다. 선택 SHA·runtime을 확인하고 새 세션에서 훅 신뢰·활성을 점검하세요. 원장·답변·선택지 ID는 자동 이전하지 않습니다. 실제 제품 설치본은 이번 배포에서 변경하지 않습니다.

[0.4.7 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.7/docs/installation.md)

## 검증 범위와 알려진 제한

동일 구현의 전체 테스트에서 905개 PASS를 확인했습니다. 환경 오류 8건은 모두 로컬 포트 바인딩 제한이며 v0.4.6에서도 동일하게 재현됐습니다. 해당 setUpClass 차단으로 9개 테스트가 미실행됐습니다. 깨끗한 checkout의 관련 테스트 47개 PASS와 독립 코드 검토도 완료했습니다. 후보 영향 검사·최종 커밋·원격 태그 신규 설치/재설치·v0.4.6 업데이트 결과는 게시 본문에서 확정합니다.

실제 UI 원문으로 확인한 복구·typed 소비 결과는 임시 시험 계약에만 적용됩니다. 신뢰된 실제 설치본 훅·전체 모델 E2E·공통 예제·실제 제품 업데이트/인수는 NOT_RUN입니다. Chrome 시작 실패·RESTART_REQUIRED 원인은 UNKNOWN이며 이번 패치로 해결됐다고 주장하지 않습니다. 원본 로그·제품 자료는 공개하지 않습니다.
