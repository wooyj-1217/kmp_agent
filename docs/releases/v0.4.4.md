# v0.4.4 지원 현황

VERSION **0.4.4**, 예정 태그 **v0.4.4**의 릴리스 후보다. 직전 실제 배포 [v0.4.3](v0.4.3.md), 커밋 `26bac4f971adf52a74f7d55ec3bf6bf85a327423`와 비교한다. [PR #18](https://github.com/wooyj-1217/kmp_agent/pull/18)의 guard 수정이 포함된 `5d573dbf14b2e0c8b38b43c44d609b4e8df62449`를 기준으로 버전·지침을 정비한다. 태그·GitHub Release 게시 전에는 배포 완료로 해석하지 않는다. 최종 배포 SHA·원격 태그 검증은 게시 단계에서 확정한다.

## v0.4.3 이후 변경

- 문서·중단 지점의 `git add`와 명시적 메시지 commit을 제품 구현 착수와 분리한다. 개발 브랜치 공유 push에는 `--no-follow-tags`를 요구하며 보호 ref·태그·삭제·force·mirror·기본 refspec은 허용하지 않는다. 저장·공유를 릴리스나 공식 완료로 인증하지 않는다.
- Stop은 대화 턴을 종료한다. `finish`는 기존 완료 검사인 `completed`와 `blocked`, `handoff`, `user_stopped`, `paused` 실행 종료를 구분하고 결과에 사유를 기록한다. 미완료 종료로 task DONE·리뷰 PASS를 만들지 않는다.
- 실제 `collaboration.*` 도구 이름을 지원한다. 임의 orchestration JS인 `functions.exec`/`exec`를 읽기로 허용하지 않는다. 자식 실행의 변경 권한은 기존 계약을 따른다.
- 독립 QA·native verification review의 승인 명령을 활성 구현과 분리한다. 정확한 세션·계획·대상 상태·구현자와 다른 actor·원본 argv 검사를 유지한다.
- 구조화 UI 검증 도구는 대상 ID·입력 전체를 한 번 동결한다. 화면·입력 action만 지원하고 출력은 `verification/` 아래로 제한하며 실행 직전 symlink를 거부한다. **CUA JavaScript REPL은 inventory만 지원**하므로 해당 REPL만 있는 환경의 UI 검증은 아직 지원하지 않는다.
- 셸의 따옴표와 실제 연산자·치환을 구분하고 제한된 `sed -n`·`git remote -v` 조회를 지원한다. 원장 JSON 손상과 독립된 읽기·저장·공유·Stop 경로를 제공한다.
- Markdown·docs JSON의 무조건 편집 예외를 제거한다. JSON 인자 초안은 `docs/guard-inputs/`, 다른 문서는 사전 동결 경로의 활성 documentation 작업 또는 해당 코드 경로의 활성 구현을 사용한다. 어떤 등록 구현 경로와 겹쳐도 문서 예외를 적용하지 않는다. 세션·작업 상태·실행·계획 누락을 오류에 구분해 표시한다.

정확한 지원 옵션·동결 입력은 [도구 경계](../guard-capabilities.md)와 [제품 실행 계약](../product-tool-enforcement.md)을 따른다. guard는 신뢰되고 활성화된 지원 훅의 검사이며 OS sandbox·branch protection·CI 배포 정책을 대체하지 않는다.

## 설치·전환

신규 설치는 게시된 v0.4.4의 새 bootstrap을 명시적으로 선택한다. v0.4.3 설치본에서는 기존 공식 관리 경로로 다음 버전을 선택할 수 있다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.4
```

태그가 게시되기 전 위 명령은 사용하지 않는다. v0.4.2 이하 guard는 관리 업데이트를 알지 못하므로 사용자 터미널의 새 bootstrap으로 첫 전환한다. [설치 안내](../installation.md)의 전환 조건을 따른다. 설치 성공·status VERIFIED는 실제 훅 신뢰/활성화·제품 인수 성공이 아니다. 기존 세션은 설치 결과의 재시작 안내에 따라 새 runtime 선택을 확인한다.

기존 documentation 작업에는 새 문서 범위가 자동으로 추가되지 않는다. 필요한 경로를 동결한 새 작업으로 인계한다. 준비 인자 JSON의 경로와 공유 push 옵션을 새 계약에 맞추며, 기존 원장·과거 실행·제품 파일·로그를 완료 상태로 재작성하지 않는다.

## 검증 범위

기준 코드 `5d573db`와 동일한 코드 트리의 clean checkout 전체 **877개 PASS**, 머지 직전 영향 검사 **121개 PASS**가 있다. 이번 버전업은 VERSION·문서 변경이므로 해당 결과를 같은 구현 파일에 한정해 재사용하고, 후보의 버전·설치·업데이트·guard 관련 **121개 검사 PASS**를 추가 확인했다(Python 3.13.18, rtk 1.2.0). 최종 후보의 추가 검사·내용 지문은 PR 검증 요약에 연결하며, 최종 원격 태그 설치·init·재설치·v0.4.3→v0.4.4 update 결과는 게시 단계에서 확정한다.

실제 Codex 훅 전달/신뢰·UI screenshot/click·실제 적용 제품 업데이트/전체 인수·기획부터 QA까지 실제 모델 E2E는 **NOT_RUN**이다. 하네스 작업의 공식 완료 인증은 보호 권한 부재로 **BLOCKED**이며 합성 시험 PASS와 구분한다. 검증 원본·원문·과거 실패 근거는 로컬에 보존하고 PR·릴리스에 업로드하지 않는다.
