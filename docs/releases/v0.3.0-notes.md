# v0.3.0

## 이번 버전 요약

기획·디자인 다음의 실제 개발 위임, 독립 QA와 담당 보완·재검증을 명시적 명령으로 연결합니다. 요청별 진행 상태와 토큰 사용량을 대시보드에서 확인하고, 원본 요구사항부터 검증 근거까지 추적할 수 있습니다.

## v0.2.0 대비 변경점

- **개발 위임 실행 추가:** 입력 해석·계획 중심이던 개발 경로에 고정 입력, 파일 소유권과 의존성, 격리 작업공간, 독립 구현 실행과 결과 검증·통합을 추가했습니다.
- **독립 QA와 보완 루프 추가:** 승인 기준별 결과·증거를 수집하고 결함을 담당 역할로 반환해 보완 후 다시 검증합니다. 시각 근거·검증 계획·재시도 한도를 연결합니다.
- **요구사항과 단계 검토 강화:** 원본 요구와 파생 명세의 누락·추가·변경을 대조하고 기획·디자인·개발계획을 각각 검토합니다. 변경 요청과 원래 요청의 최종 판정을 구분합니다.
- **대시보드 확장:** Main·작업 이력·토큰 메뉴에서 실행, 산출물, 승인 기준, 차단 사유와 재검증 필요 상태를 확인합니다. 에이전트 보고와 같은 근거로 진행 체크리스트를 표시합니다.
- **토큰 추적 개선:** 응답별 사용량의 수집·분류·중복 제거와 작업·역할·목적·재작업별 집계를 개선했습니다.
- **공통 운영 지침 보강:** 디자인 시안·검증, 진행 보고, PR 준비·제출·한국어 커밋 규칙을 정리하고 제출 범위·필수 파일·내용 해시·상대 링크 검사 도구를 추가했습니다.
- **QA 결함 수정:** 검증하지 않은 담당 기준에 전체 PASS가 복사되는 문제를 막고, 실패 시 실행 정리, 생성 경로의 입력·소스 중첩 차단, 개별 증거와 현재 산출물의 유효성 검사를 보강했습니다.

## 지원 범위와 제약

명령 안에서 위임·검증·보완을 처리하며, 상시 감시나 역할 간 무지시 자동 연쇄·자동 PR 생성은 제공하지 않습니다. 대시보드는 읽기 전용입니다. 토큰·비용에는 미귀속·UNKNOWN이 남을 수 있으며 실제 청구액을 인증하지 않습니다.

[태그 기준 지원 범위](https://github.com/wooyj-1217/kmp_agent/blob/v0.3.0/docs/releases/v0.3.0.md)

## 설치·업데이트

최초 설치는 [설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.3.0/docs/installation.md)의 `--ref v0.3.0`을 사용합니다. 기존 설치는 제품 저장소 루트에서 다음 명령으로 명시적으로 업데이트합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.3.0
rtk proxy python3 .kmp-agent/agent.py status
```

기존 설치본과 이미 동결한 역할 입력은 자동 갱신되지 않습니다. 대상의 `/hooks`에서 훅 정의를 검토·신뢰하고 새 세션에서 활성 상태를 확인해야 합니다.

## 검증 범위

최종 배포 SHA와 원격 태그 설치·업데이트 결과는 GitHub Release 게시 본문에 기록합니다. PR 검토에서 관련 회귀 150개와 대시보드 자원 HTTP 10개·JavaScript 구문 5개 검사를 통과했습니다. 최종 후보는 해당 실행 코드·시험·정적 자원의 동일성을 대조합니다. 실제 모델 호출, 설치본의 새 Codex 세션·훅 활성화, 실제 적용 프로젝트·네이티브 앱 전체 검증은 미실행입니다.
