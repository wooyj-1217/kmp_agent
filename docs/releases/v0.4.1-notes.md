# v0.4.1 — 게시 본문 원본

제품 기술 계약 검사를 실제 도구 실행과 종료 경계에 연결합니다. 승인된 구현 작업 없이 소스를 수정하거나 임의 프로그램을 실행하는 경로를 제한하고, 제품 작업이 공식 완료되기 전의 게시·종료를 차단합니다.

## v0.4.0 대비 변경

- 추가: 설치 프로젝트의 PreToolUse·Stop guard. 기존 native 작업·승인·단계·기술 계약·코드 소유 범위를 재사용합니다.
- 수정: TODO 등록만으로 소스를 수정하는 경로, 임의 역할 worker·QA/위임 adapter 실행, Git 읽기 옵션을 통한 프로그램 실행·파일 출력 우회를 차단합니다.
- 변경: 설치 init은 기존 제품 훅을 보존하면서 검사 훅을 추가합니다. 직접 인터프리터나 관리되지 않은 실행은 거절되므로 승인된 제품 명령 경로를 사용해야 합니다.

## 설치·업데이트와 전환

기존 v0.4.0 설치는 제품 루트의 **사용자 터미널**에서 다음 명령으로 업데이트합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.1
rtk proxy python3 .kmp-agent/agent.py status
```

새 PreToolUse·Stop 검사 훅을 `/hooks`에서 검토·신뢰하고 새 Codex 세션에서 실제 허용·거절을 확인해야 합니다. status의 VERIFIED는 수집 확인이며 guard 활성화 인증을 대신하지 않습니다. init/update/recover는 guard가 활성화된 Codex 도구 안에서 raw 실행하지 않고 사용자 터미널을 사용합니다.

[0.4.1 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.1/docs/installation.md) · [지원 범위](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.1/docs/releases/v0.4.1.md)

## 검증·제약

게시 본문은 VERSION 0.4.1·태그 v0.4.1의 최종 전체 SHA, 최종 코드 검사와 원격 신규 설치·v0.4.0 업데이트 결과를 확정해 작성합니다. 제품 파일·로그·project ID 보존과 실제 훅 신뢰·로드를 구분합니다. 원본 로그·캡처·검증 JSON은 로컬에 보존하며 배포 자료에 첨부하지 않습니다.

기존 main에서도 재현되는 위임 테스트의 `DONE != BLOCKED` 실패가 있으며 전체 회귀 PASS를 주장하지 않습니다. 전체 실제 모델 E2E와 제품 전체 인수는 미실행입니다. 이 보호는 지원되고 신뢰·활성화된 훅에 한정되며 OS sandbox나 서버 보호 정책을 대체하지 않습니다.
