# v0.4.2 지원 현황

VERSION **0.4.2**, 예정 태그 **v0.4.2**의 후보 제공 범위다. 존속하는 직전 배포 [v0.4.1](v0.4.1.md), 커밋 `2f24f681eae80341b9627363108191815e78dc90`과 비교한다. 2026-11-12 사용자 명시 요청으로 v0.5.0 태그·GitHub Release를 철회하고 그 변경과 guard 개선을 이 버전에 포함한다. 기존 커밋 이력·과거 검증 원본은 보존한다. 최종 커밋·원격 검증·삭제/게시 결과는 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.2)에서 확정한다.

## v0.4.1 이후 변경

- 클라이언트 KMP 필수 기준을 공통 지침·역할 입력·개발 위임에 전달한다. 제품별 타깃·로직/UI 공유·서버 기술을 별도로 확정하며, 비 KMP 입력은 구현 전 계약 충돌로 반환한다. 산출물의 KMP 사용을 자동 판별하는 새 게이트는 아니다.
- 신규 제품 첫 개발에는 DB 기본값 사용/다른 지정을 한 번 확인한다. 서버 기본안은 PostgreSQL + Exposed SQL DSL(JDBC) + Flyway, 로컬 기본안은 SQLite + SQLDelight다. 미응답을 승인으로 취급하지 않고 진행 중인 제품의 기존 스펙을 유지한다.
- [UI 비해당 계약](../ui-applicability.md)은 원본·현재 승인·동결 입력과 독립 인터페이스 검토를 요구한다. `visual_required=False`만으로 개발 인계를 허용하거나 시각 PASS를 만들지 않는다.
- [제품 예제 분리](../examples-separation.md)로 제품별 문서·fixture·시험 도구를 현재 공통 tree와 새 설치 입력에서 제외한다. 과거 Git 객체와 로컬 원본은 보존하며 companion을 자동 입력하지 않는다.
- 개발 추적의 불변 Git 객체 캐시·refresh 시간 제한·종료 시 최신성 확인, 설치 CLI의 표준 logging 충돌과 사용량 복구 시험의 비공개 경로 의존을 수정한다.
- 제품 guard의 CUA 지원은 직접 inventory 조회 문법으로 한정한다. 임의 JavaScript·바인딩·UI 상호작용·탐색·변경은 여전히 차단한다. 작업 목록 조회는 새 작업 생성이나 작업 디렉터리 전환 권한이 아니다.
- 외부 저장소 Git 조회는 pager·fsmonitor·선택적 잠금을 끈 명시적 status 관측만 지원한다. 다른 저장소 변경은 해당 저장소 루트의 별도 작업으로 인계한다.
- 개발 착수·재개에 필요한 단계 워크플로·독립 개발계획 검토·현재 입력 연결 누락을 진단한다. 기존 Markdown이나 소스 검토를 계약 PASS로 자동 승격하지 않는다.

## 설치·업데이트와 전환

신규 설치와 v0.4.1 또는 철회된 v0.5.0에서의 전환은 [설치 안내](../installation.md)의 **새 v0.4.2 bootstrap**으로 명시적으로 실행한다. 버전 숫자가 낮아졌다는 이유로 기존 설치가 자동 변경되지는 않는다. 기존 설치기의 파일 선별 정책을 재사용하지 않도록 첫 전환도 새 bootstrap을 사용한다.

```sh
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py update --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.2 --target /path/to/product
```

사용자 터미널에서 실행하고 `/hooks`의 수집·PreToolUse·Stop 정의를 검토·신뢰한 뒤 새 Codex 세션에서 실제 허용/차단을 확인한다. 설치·정적 연결 또는 status의 VERIFIED를 guard 활성화·제품 전체 PASS로 확대하지 않는다. 제품의 기존 결정·데이터·로그·완료 이력을 새 버전으로 재작성하지 않는다.

## 검증 범위

현재는 릴리스 준비 단계다. 이번 수정의 최종 clean checkout 회귀, 최종 태그 신규 설치·init·재설치와 v0.4.1/v0.5.0에서의 명시적 update, 원격 SHA·VERSION·clean 및 데이터 보존 결과는 아직 확정하지 않았다. 게시 전 실제 실행 결과를 본문에 기록한다.

이전 v0.5.0 준비 과정의 clean 803개 회귀, 제한된 실제 모델 KMP CLI·JUnit·31개 CLI 사례와 동결 사용량 corpus 검증은 당시 범위의 역사 근거다. 코드가 변경된 이번 후보의 재실행 PASS로 승계하지 않는다. JS·Android·iOS·시각 UI·운영 DB·제품 API·실제 적용 제품 전체 인수와 이번 태그 실제 세션 훅 활성화는 별도 검증 대상이다. guard는 신뢰·활성화된 지원 훅의 보호이며 OS sandbox나 branch protection을 대체하지 않는다.
