# v0.4.16 지원 범위

직전 배포판은 v0.4.15입니다. 구현 변경은 [PR #38](https://github.com/wooyj-1217/kmp_agent/pull/38)에서 확인할 수 있습니다.

| 흐름 | 변경 및 확인 범위 |
| --- | --- |
| 설치·초기화·업데이트 | 고정 ref 설치와 공식 업데이트 경로를 사용합니다. |
| 요구·단계 준비 | 누적 단계 재작업 한도를 제거했습니다. 작업별 계약과 인간 결정 기록은 적용됩니다. |
| 디자인·시안·검토 | 재검토에 동일한 단계 보완 정책을 적용합니다. |
| 개발·명령 실행 | 서비스와 승인된 검증 명령을 하나의 작업 잠금에서 실행할 수 있습니다. |
| QA·검증 | 검증 명령마다 승인과 실행 기록을 확인합니다. |
| 실패 반환·보완·재검증 | 확인된 프로세스 종료와 명령 로그 복구 뒤 같은 시도에서 이어갈 수 있습니다. |
| 완료·제출·인계 | 기존 승인과 작업 시도를 보존합니다. |
| 산출물·실행·로그 | 원래 로그가 늦게 복구돼도 기존 명령 근거를 유지합니다. |
| 하네스 결함·PR | 관련 회귀와 릴리스 후보 검증을 별도로 기록합니다. |

복합 서비스 검증과 명령 로그 연결에는 명시적 호출이 필요합니다. 제품 경로 검증과 배포 결과는 완료된 경우 GitHub Release에서 확인할 수 있습니다.
