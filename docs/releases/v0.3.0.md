## 검증과 사용 전제

2026-10-29 PR 검토 기준 관련 회귀 150개, 대시보드 자원 HTTP 10개·JavaScript 구문 5개, diff 검사가 통과했다. 배포 후보에서 이 실행 코드·시험·정적 자원의 동일성을 확인하고 VERSION·문서 변경과 원격 설치 경로를 별도 검사한다. 과거 전체 회귀는 실행 중 변경이 있어 최종 버전 전체 PASS 근거로 사용하지 않는다. 최종 원격 결과는 게시 본문에 확정한다.

POSIX·Python 3.10+·Git·rtk와 원격 접근 권한이 필요하며 실제 역할 실행은 Codex 환경·권한이 추가로 필요하다. 실제 모델, 설치본 새 Codex 세션·훅 활성화, 실제 적용 프로젝트·네이티브 앱 전체 검증은 미실행이다. 제품 결과와 로그는 제품에 보관한다.

## 태그 준비 정정

2026-10-29: 최초 v0.3.0 태그의 내부 VERSION이 0.2.0으로 남아 있음을 확인했다. Release 게시 전에 사용자 지시에 따라 VERSION·설치 안내·지원 문서를 0.3.0으로 정정하고 태그를 정정 커밋에 맞춘다. 이전 태그를 이미 가져온 경우 태그 ref를 명시적으로 갱신하거나 최종 Release의 전체 SHA를 선택해야 한다. 기존 설치본은 자동으로 바뀌지 않는다.
