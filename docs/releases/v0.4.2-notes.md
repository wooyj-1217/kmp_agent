# v0.4.2 — 도구 관측과 개발계획 재개 경계 보완

제품 guard에서 제한된 CUA 상태 조회와 작업 목록 탐색, 안전한 외부 Git status 관측을 지원합니다. 개발 착수·재개는 누락된 단계 계약과 현재 입력 연결을 안내하며 독립 개발계획 검토를 유지합니다. 사용자 요청에 따라 v0.5.0을 철회하고 해당 변경까지 이 버전에 포함합니다.

## v0.4.1 대비 변경

- 추가: 제한된 도구 관측과 출처에 연결된 UI NOT_APPLICABLE 계약.
- 변경: KMP 필수 기준과 신규 제품 첫 개발의 DB 기본값 확인. 진행 중인 제품은 기존 스펙을 유지합니다.
- 수정: 단계 계약 누락 진단·재개 검사, 개발 추적의 최신성·시간 제한, 설치 CLI logging 충돌, 사용량 회귀의 비공개 경로 의존.
- 제거: 공통 현재 tree·설치 입력의 제품 예제·전용 도구. 기존 커밋 이력과 로컬 원본은 보존합니다. v0.5.0 태그·Release 철회는 이번 사용자 요청에 한정합니다.

## 지원 범위와 제약

명시적 명령과 기존 foreground 연쇄 실행을 제공합니다. CUA는 직접 inventory 조회만 지원하며 임의 JavaScript·UI 상호작용·탐색·변경은 허용하지 않습니다. 외부 Git은 안전 옵션을 고정한 status 관측만 지원합니다. 작업 목록 탐색은 작업 디렉터리 전환이 아니며, 구현·검토·완료 gate를 생략하지 않습니다. 자동 머지·릴리스·제품 업데이트 연쇄, 상시 변경 감시는 제공하지 않습니다.

[0.4.2 지원 현황](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.2/docs/releases/v0.4.2.md)

## 설치·업데이트와 마이그레이션

게시된 v0.4.2와 아직 없는 bootstrap 경로를 사용합니다.

```sh
rtk proxy git clone --depth 1 --branch v0.4.2 git@github.com:wooyj-1217/kmp_agent.git /tmp/kmp-agent-bootstrap
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py install --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.2 --target /path/to/product
```

v0.4.1 또는 철회된 v0.5.0에서 전환할 때도 위의 **새 v0.4.2 bootstrap**으로 실행합니다.

```sh
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py update --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.2 --target /path/to/product
```

사용자 터미널에서 명시적으로 실행하고 `/hooks`의 수집·검사 정의를 검토·신뢰한 뒤 새 Codex 세션에서 실제 동작을 확인하세요. 기존 제품 결정·데이터·로그를 기본값으로 덮어쓰지 않습니다. status의 VERIFIED는 실제 guard 활성화나 제품 완료와 별도입니다.

[0.4.2 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.2/docs/installation.md)

## 검증 범위

사용자 승인에 따라 PR 검증·머지 후 최종 태그의 원격 설치·update 검증을 거쳐 게시합니다. 최종 실행 코드의 clean checkout 회귀 131개는 PASS입니다. 개발 중 전체 회귀 825개 실행에서 loopback bind 권한 오류 8건이 발생해 해당 4개 모듈을 권한 있는 환경의 clean checkout에서 재검증해 36개 PASS를 확인했습니다. 최종 배포 커밋·원격 태그 신규 설치·init·재설치와 v0.4.1/v0.5.0 update 결과는 게시 본문에서 별도로 확정하며, 위 회귀 결과를 해당 원격 검증의 PASS로 대신하지 않습니다. 과거 v0.5.0의 테스트와 실제 모델 시험은 이번 수정의 재실행 PASS로 승계하지 않습니다. 실제 적용 제품 전체 인수·이번 태그의 실제 세션 훅 활성화·JS/mobile/시각 UI/운영 DB/제품 API는 별도 검증 대상입니다. 원본 증거는 로컬에 보존합니다.
