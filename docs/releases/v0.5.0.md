# v0.5.0 지원 현황

2026-11-12 정정: 사용자가 v0.5.0 태그·GitHub Release 삭제 후 guard 개선을 포함한 [v0.4.2](v0.4.2.md) 재배포를 명시적으로 요청했다. 이 문서는 `f0f47ffca2df29dce1141bba9a437339d689da9f`의 당시 제공 범위·검증 설명을 보존한 역사 기록이다. 태그/Release 철회 완료는 실제 원격 상태로 확인하며, 아래 설치 명령을 현재 권장 경로로 사용하지 않는다. 기존 커밋 이력·로컬 검증 원본은 보존한다. 삭제 요청은 이번 버전에 한정한 예외다.

당시 VERSION은 **0.5.0**, 태그는 **v0.5.0**, 비교 기준은 [v0.4.1](v0.4.1.md)이었다. 현재 설치·업데이트 경로는 [설치 안내](../installation.md)를 따른다.

## v0.4.1 이후 변경

- 클라이언트 KMP 필수 기준을 공통 지침·역할 입력·개발 위임에 전달한다. 플랫폼·로직/UI 공유·서버 기술은 제품별로 정하며, 비 KMP 요구는 구현 전 계약 충돌로 반환한다. 산출물의 KMP 사용을 자동 판별하는 새 게이트는 아니다.
- DB 기본값은 서버 PostgreSQL + Exposed SQL DSL(JDBC) + Flyway, 로컬 SQLite + SQLDelight다. 신규 제품 첫 개발에는 기본값 사용/다른 지정을 한 번 확인하고, 진행 중인 제품은 기존 확정 스펙을 따른다. DB 필요 여부나 저장 역할을 임의 가정하거나 미응답을 채택 승인으로 처리하지 않는다.
- [UI 비해당](../ui-applicability.md)은 명시적 계약을 현재 요구사항 계보에 연결·동결한다. CLI 인터페이스 설계·독립 검토는 유지하며 시안·시각 QA는 NOT_APPLICABLE로 구분한다. visual_required=True 또는 False만으로 인계를 우회하지 않는다.
- 제품 예제·메모 도구·Ktor fixture·제품 전용 시험을 [공통 HEAD와 설치 입력에서 분리](../examples-separation.md)한다. 원본과 companion은 로컬 보존이며 별도 공개 저장소를 제공하지 않는다. 과거 Git 이력·태그는 유지하므로 full clone은 역사 객체도 받을 수 있다.
- 개발 추적은 불변 Git 객체만 재사용하고, 각 refresh의 전체 시간 제한과 종료 시 파일·모드·symlink·Git 상태를 재검사한다. 조회는 갱신 후 상태를 반환한다. 설치 CLI 직접 실행의 표준 logging 모듈 충돌도 수정한다.
- 사용량 복구 회귀는 필수 합성 시험과 명시적 실제 corpus 선택 검증을 구분하며 비공개 경로의 묵시적 skip 의존을 제거한다. 합성 시험을 실제 모델 실행으로 표시하지 않는다.

## 설치·업데이트와 전환

신규 설치와 v0.4.1에서의 첫 전환은 [설치 안내](../installation.md)의 **v0.5.0 bootstrap**을 사용한다. 기존 설치기에서 update를 호출할 때는 그 설치기의 선별 정책이 적용되므로, 첫 전환에서도 새 bootstrap을 사용해 파일 선별·검증을 수행한다.

```sh
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py update --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.5.0 --target /path/to/product
```

제품의 사용자 터미널에서 명시적으로 실행한다. 원본 코드·제품 데이터·기존 로그·동결된 완료 이력을 새 버전으로 재작성하지 않는다. `/hooks`에서 수집·PreToolUse·Stop 훅을 검토·신뢰하고 새 Codex 세션에서 활성 상태와 허용/거절을 확인한다. status의 VERIFIED는 수집 범위이며 guard 활성화나 제품 전체 완료를 인증하지 않는다. 직접 참조 모드는 설치 모드와 다르며 원본 최신 HEAD를 자동 전파하지 않는다.

## 검증 범위와 알려진 제한

PR15 최종 코드의 clean checkout 전체 회귀는 **803 PASS / 0 FAIL / 0 ERROR / 0 SKIP**다. 배포 후보에서 실행 코드·테스트 내용 해시 동일성을 대조하고 VERSION·설치·문서 영향 검사를 추가한다. 최종 원격 태그의 결과는 Release 본문에 확정하며 코드가 같다는 이유만으로 태그 설치를 실행했다고 쓰지 않는다.

제한된 실제 모델 KMP CLI 시험은 기획·디자인·개발 계획 및 독립 검토, 실제 모델 구현 뒤 JVM 빌드·JUnit 6개·정확한 CLI 31개 사례, 독립 모델 소스/완료된 실행 근거 검토와 별도 실제 QA 명령을 통과했다. 캐시 경로·권한·디스크 문제 뒤 수동 재검증을 거쳤으므로 전체 자동 오케스트레이션 성공이 아니다. visual_required=True와 비해당 계약의 충돌 거부도 확인했다.

실제 동결 메모 사용량 corpus 64응답/3,753,506토큰은 합계·원본 불변·재수집 멱등성을 검증했다. 이는 모델 재실행이 아니다. 원래 private legacy corpus는 부재로 NOT_RUN이며 필수 합성 검사와 구분한다. 메모 앱의 과거 모델·브라우저 검증을 이번 배포 커밋의 재실행으로 확대하지 않는다.

JS·Android·iOS·시각 UI·운영 DB·제품 API와 실제 적용 제품 전체 인수는 이번 CLI 시험에서 미실행이다. 이전 배포의 실제 훅 검증을 이번 태그의 새 세션 검증으로 바꾸지 않는다. guard는 신뢰·활성화된 지원 훅의 보호이며 OS sandbox·서버 branch protection을 대체하지 않는다. 원본 증거는 로컬에 보존하고 배포 파일에 싣지 않는다.
