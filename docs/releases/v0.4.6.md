# v0.4.6 지원 현황

VERSION **0.4.6**, 태그 **v0.4.6**의 제공 범위다. 직전 실제 배포 [v0.4.5](v0.4.5.md), 커밋 `c5bdbe64067b1e6a62165cf8906c52e00ecb3688` 이후 [PR #22](https://github.com/wooyj-1217/kmp_agent/pull/22)·[PR #23](https://github.com/wooyj-1217/kmp_agent/pull/23)의 수정을 묶은 패치다. 준비 기준은 두 PR이 머지된 `7fb456a470873a7c26471d8a45436246eaeb25c8`이며 최종 배포 SHA·원격 검증·게시 결과는 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.6)에서 확정한다.

## v0.4.5 이후 수정

- 설치 프로젝트의 관리 AGENTS 블록과 공통 지침 앞부분에 단일 셸 명령·headroom `hash` 입력을 안내한다. 상세 지침을 읽기 전 호출 형식을 확인할 수 있고 오류에도 재시도 예시를 제공한다. 복합 셸·잘못된 `id` 키의 거부 조건은 유지한다.
- 훅이 전달한 `collaborationspawn_agent` 등 여섯 검토 동작의 정확한 이름과 `web.run`·`web__run`·`webrun` 조회를 지원한다. 임의 이름 정규화·exec 스크립트의 포괄 허용은 하지 않는다. 세션 진단은 정확히 `printenv CODEX_THREAD_ID`, `ps -axo pid,args`만 추가한다.
- 공식 `task --operation revise-execution-plan`으로 새 작업 또는 이미 등록된 미착수 후속 단계를 전체 계획에 연결한다. 이유·근거·이력을 남기며 같은 프로젝트/작업 종류, 중복·시작 이력·타 계획 소속·EXCLUDED 검사를 원자적으로 적용한다. 각 담당 상세 계획과 ready/begin은 별도다.
- design documentation 작업이 정확히 등록한 `docs/`·`prototype/` HTML/CSS 시안 경로와 루트 `project-settings.json` 초안을 지원한다. 활성 세션·계획·실행과 등록된 구현 경로 중첩 검사는 유지한다. 초안 편집은 실행·원본 승인·동결 계약을 대신하지 않는다.
- 정책·전체 계획·상세 계획의 준비 순서를 안내하고 task 거절에 업데이트용 recover 안내를 잘못 표시하지 않는다.

제품 기술 승인·단계 검토·코드 소유권·ready/begin과 정식 완료 조건은 유지한다. [도구 경계](../guard-capabilities.md), [준비 순서](../product-tool-enforcement.md), [계획 확장](../execution-policy.md#이미-시작한-전체-계획에-단계-추가)을 따른다.

## 설치·전환

신규 설치는 [설치 안내](../installation.md)의 v0.4.6 bootstrap을 사용한다. v0.4.3~v0.4.5 설치본은 기존 source를 재사용하는 단일 관리 명령으로 선택한다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.6
```

다른 셸 명령·`--source`·`--target`과 결합하지 않는다. v0.4.2 이하는 사용자 터미널에서 새 bootstrap으로 전환한다. 선택 SHA·runtime·새 시작 안내를 확인하고 새 세션에서 훅 신뢰/활성 상태와 실제 도구·준비 경로를 검증한다. 설치 성공은 실제 모델이 안내를 준수하거나 원래 제품 작업이 해결됐다는 증거가 아니다. 제품 코드·로그·원장과 과거 배포 기록은 보존하며 이번 릴리스가 실제 제품에 자동 적용되지는 않는다.

## 검증 범위

PR #22·#23 통합 트리의 깨끗한 checkout에서 관련 **196개 PASS**, 18개 파일의 범위·내용 해시·상대 파일 링크 대조 PASS와 실제 머지 main 트리 일치를 확인했다. 이번 후보는 같은 구현의 버전·문서 정비이며 후보 checkout의 영향 검사와 신규 설치·init·재설치·v0.4.5→v0.4.6 update 검증을 별도로 수행한다. 최종 커밋 적용성·검사 결과·원격 태그 설치 결과는 Release 게시 본문에서 확정한다.

합성 설치 fixture의 도구 분류·공식 CLI·초기 지침 전달 시험과 실제 호스트 훅은 구분한다. 신뢰된 실제 Codex 훅·웹/headroom 서비스·UI runtime·실제 모델 전체 E2E·공통 예제·실제 적용 제품 업데이트/인수는 **NOT_RUN**이다. OS 샌드박스 오류를 이번 수정의 해결 항목으로 주장하지 않는다. 보호 권한이 필요한 공식 완료 인증은 기존 BLOCKED 상태이며 시험 PASS와 별개다. 검증 원본은 로컬에 보존하고 공개하지 않는다.
