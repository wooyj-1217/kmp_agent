# v0.4.5 — 지침 원문 조회와 새 프로젝트 준비 경로 복구

최종 배포 SHA와 원격 태그 검증 결과는 게시 본문에서 확정한다.

## v0.4.4 대비 수정

압축된 지침 출력의 원문 복원과 공식 도움말 조회가 제품/UI 검증으로 막히던 문제를 수정합니다. 앱 소스·원장이 없는 프로젝트에서도 새 기획·문서 작업을 준비할 수 있도록 설치용 명령과 JSON 경로를 맞춥니다.

- headroom 원문 조회는 hash-only 읽기 계약으로 허용합니다.
- 공식 launcher의 단독 `--help`는 제품 상태와 분리하며 경로·원문·symlink/별칭을 검사합니다.
- 미지원 도구에는 이름과 복구 경로를 표시하고 실제 UI action만 UI 검증을 요구합니다.
- 설치 프로젝트에는 `.kmp-agent/agent.py task`와 `docs/guard-inputs/`를 안내합니다. 복합 셸은 계속 거부하며 조회는 단순 명령으로 나눕니다.

제품 코드 작성의 기술 승인·단계 검토·ready/begin은 유지합니다. 기획 작업 등록은 구현 착수나 완료 승인이 아닙니다. 임의 exec wrapper·임의 Python 실행 허용을 추가하지 않습니다.

[0.4.5 지원 현황](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.5/docs/releases/v0.4.5.md)

## 설치·업데이트

게시된 v0.4.5의 새 bootstrap으로 신규 설치합니다. v0.4.3·v0.4.4 설치본에서는 프로젝트 루트에서 다음 단일 명령을 사용합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.5
```

기존 source를 사용하므로 `--source`, `--target` 또는 다른 셸 명령을 덧붙이지 않습니다. v0.4.2 이하의 첫 전환은 사용자 터미널의 새 bootstrap이 필요합니다. 새 세션·훅 신뢰/활성 상태는 설치 결과에 따라 확인하고 실제 조회/준비를 다시 검증하세요. 실제 제품 설치본은 이 릴리스 작업에서 변경하지 않습니다.

[0.4.5 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.5/docs/installation.md)

## 검증 범위

동일 구현의 clean 관련 검사 189개와 핵심 9개 PASS를 구현 파일에 한정해 재사용합니다. 버전·설치·관리 update·조회/guard 관련 후보 검사 130개 PASS를 추가 확인했으며, 최종 SHA·원격 태그 설치 및 v0.4.4→v0.4.5 관리 update 결과는 게시 본문에서 확정합니다.

설치본의 실제 Codex 세션에서 신뢰된 훅을 거치는 headroom 서비스 호출·원문 복원, UI 연결·공통 예제 실행·실제 적용 프로젝트·실제 모델 전체 E2E는 NOT_RUN입니다. 공식 완료 인증은 보호 권한 부재로 BLOCKED이며 테스트 PASS와 다릅니다. 설치 fixture의 도구 분류·실제 help·TODO 등록을 실제 호스트 훅 실행과 구분합니다.
