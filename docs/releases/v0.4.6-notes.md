# v0.4.6 — 제품 준비 경로와 첫 호출 안내 보완

v0.4.5 이후의 수정 PR #22·#23을 묶은 패치 릴리스입니다. 최종 배포 SHA와 원격 검증 결과는 게시 본문에서 확정합니다.

## v0.4.5 대비 수정

- 상세 지침을 읽기 전에 단일 명령 실행과 정확한 headroom `hash` 입력을 안내하고 오류에 재시도 예시를 표시합니다.
- 실제 훅의 검토 도구·웹 조회 이름과 제한된 세션 진단을 지원합니다.
- `task --operation revise-execution-plan`으로 신규·기존 미착수 후속 단계를 전체 계획에 연결합니다. 프로젝트·작업 종류·타 계획 소속·시작 이력 검사와 변경 근거는 유지합니다.
- design documentation의 정확한 HTML/CSS 시안 경로와 루트 설정 초안을 등록할 수 있고, 준비 순서별 복구 명령을 안내합니다.

준비 명령은 수동 호출하며 명령 내부에서 계약을 검사합니다. 제품 기술 승인·단계 검토·ready/begin은 유지합니다. 문서 초안·계획 연결·검토 도구 호출은 제품 구현/완료 승인이 아닙니다. 안내 전달이 실제 모델의 첫 호출 준수를 자동 보장하지 않습니다.

[0.4.6 지원 현황](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.6/docs/releases/v0.4.6.md)

## 설치·업데이트

신규 설치는 게시된 v0.4.6의 bootstrap을 명시 선택합니다. 아래 경로는 아직 없는 임시 경로와 제품의 실제 Git 루트로 바꾸세요.

```sh
rtk proxy git clone --depth 1 --branch v0.4.6 git@github.com:wooyj-1217/kmp_agent.git /tmp/kmp-agent-bootstrap
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py install --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.6 --target /path/to/product
```

v0.4.3~v0.4.5 설치본에서는 프로젝트 루트에서 다음 단일 명령을 사용합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.6
```

기존 source를 사용하므로 `--source`, `--target`이나 다른 셸 명령을 덧붙이지 않습니다. v0.4.2 이하는 사용자 터미널의 새 bootstrap으로 전환합니다. 설치 후 선택 SHA·runtime·초기 안내를 확인하고 새 세션에서 훅 신뢰·활성과 원래 차단 작업을 다시 검증하세요. 실제 제품 설치본은 이 릴리스 작업에서 변경하지 않습니다.

[0.4.6 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.6/docs/installation.md)

## 검증 범위와 알려진 제한

동일 구현의 clean 통합 검사 196개 PASS를 확인했습니다. 버전·문서 후보의 검사와 최종 커밋·원격 태그 신규 설치/재설치·v0.4.5 업데이트 결과는 게시 본문에서 확정합니다. 원본 로그·제품 자료는 공개하지 않습니다.

신뢰된 실제 Codex 훅·웹/headroom/UI 서비스·실제 모델 전체 E2E·공통 예제·실제 제품 적용/인수는 NOT_RUN입니다. OS 샌드박스의 app-server 초기화 실패는 별도 환경 문제이며 이번 수정으로 해결됐다고 주장하지 않습니다. 보호 권한이 필요한 공식 완료 인증은 BLOCKED이며 테스트 PASS와 다릅니다.
