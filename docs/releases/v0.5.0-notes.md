# v0.5.0 — KMP·DB 기준과 UI 비해당 지원

2026-11-12 정정: 사용자 요청으로 v0.5.0 태그·Release를 철회하고 guard 개선을 포함한 [v0.4.2](v0.4.2.md)로 대체한다. 아래는 당시 본문 원본을 보존한 기록이며 현재 설치 안내가 아니다. 실제 삭제·재게시 상태는 원격에서 확인한다.

KMP 개발 기준과 DB 기본값 확인 절차를 공통 입력에 반영합니다. CLI처럼 UI가 없는 제품도 명시적인 비해당 계약, 인터페이스 설계·독립 검토를 거쳐 개발에 인계할 수 있습니다. 제품 예제와 시험 자료를 공통 HEAD 및 설치 입력에서 분리합니다.

## v0.4.1 대비 변경

- 추가: 출처와 연결된 UI NOT_APPLICABLE 계약 및 no-UI 개발 인계.
- 변경: KMP 필수 기준, 첫 개발의 DB 기본값 사용/변경 확인. 진행 중인 제품은 기존 스펙을 유지합니다. 서버 기본값은 PostgreSQL + Exposed SQL DSL/JDBC + Flyway, 로컬은 SQLite + SQLDelight입니다.
- 수정: 코드 추적의 최신성·시간 제한과 설치 CLI의 표준 logging 모듈 충돌, 사용량 복구 시험의 비공개 경로 의존.
- 제거: 현재 공통 트리와 설치 입력의 제품 예제·메모 도구·전용 시험. 원본은 로컬 보존하며 companion 원격은 제공하지 않습니다. 과거 Git 이력·태그는 유지합니다.

## 지원 범위와 제약

명시적 명령과 기존 foreground 연쇄 실행을 지원하며 자동 머지·릴리스·제품 업데이트를 제공하지 않습니다. 반환 작업의 own-OPEN 차단과 일반 planning revision 계약 자동 연결의 기존 제한이 남습니다. 실제 CLI 시험은 수동 환경 재검증을 거쳤으며 전체 자동 E2E나 제품 전체 PASS가 아닙니다.

## 설치·업데이트와 마이그레이션

아직 없는 빈 bootstrap 경로와 실제 제품 저장소 루트를 사용합니다.

```sh
rtk proxy git clone --depth 1 --branch v0.5.0 git@github.com:wooyj-1217/kmp_agent.git /tmp/kmp-agent-bootstrap
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py install --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.5.0 --target /path/to/product
```

v0.4.1에서 첫 전환도 위의 **새 v0.5.0 bootstrap**으로 실행합니다.

```sh
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py update --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.5.0 --target /path/to/product
```

사용자 터미널에서 실행하고 `/hooks`의 수집·검사 훅을 검토·신뢰한 뒤 새 Codex 세션에서 활성 상태를 확인하세요. status의 VERIFIED와 실제 훅 활성화·제품 완료는 별도입니다. 기존 제품 스펙·데이터·로그를 기본값으로 덮어쓰지 않습니다. 전체 clone은 과거 예제 Git 객체도 받을 수 있습니다.

[0.5.0 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/f0f47ffca2df29dce1141bba9a437339d689da9f/docs/installation.md)

## 검증 범위

- 동일 코드의 clean 전체 회귀 803개 통과(실패·오류·건너뜀 0개), 배포 후보의 코드/테스트 해시 일치 및 버전·설치·문서 영향 검사를 대조합니다.
- 실제 모델 KMP CLI 구현, JVM 빌드·JUnit 6개·CLI 31개 사례와 독립 소스/실행 근거 QA 통과. 수동 환경 재검증을 포함합니다.
