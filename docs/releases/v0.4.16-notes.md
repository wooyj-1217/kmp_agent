# v0.4.16

기존 승인 범위에서 단계 보완과 관리 명령을 이어 실행하기 쉬워졌습니다.

- 단계 전체 누적 보완 한도를 제거했습니다. 작업별 시도 한도와 명시적으로 설정한 역할 실행 한도는 적용됩니다.
- 같은 작업에서 서비스를 띄운 상태로 승인된 검증 명령을 실행하고, 검증이 끝나면 서비스 프로세스 그룹을 정리합니다.
- 등록을 마친 포그라운드 명령을 취소하면 정리가 확인된 경우 실제 비정상 종료 코드를 남겨 같은 시도에서 다음 명령을 실행할 수 있습니다.
- 최초 명령 로그가 빠졌을 때 새 명령 로그를 연결할 수 있습니다. 원래 로그가 늦게 복구돼도 기존 검증 근거와 연결이 유지됩니다.

프로젝트 루트에서 `rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.16`로 업데이트합니다. [설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.16/docs/installation.md)
