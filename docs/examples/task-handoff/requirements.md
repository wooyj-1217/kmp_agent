# 메모 작성 — 기획 인계 시험 산출물

- 기능 ID·이름: EX-FEAT-001 / 메모 작성(제품 미확정)
- 하네스 작업: FEAT-001 / TASK-001. 아래 EX 수용 기준은 제품 예제이며 TASK의 문서 검토 기준과 구분한다.
- 디자인: [design.md](design.md)
- 범위: 기획에서 디자인으로 문서를 전달하는 시험. 실제 기능 검증은 NOT_RUN.

## 문제·사용자·목표

짧은 생각을 기록하려는 사용자라는 가설을 사용해 입력·저장·실패 흐름을 설명하고, 수용 기준이 디자인으로 전달되는지 확인한다.

## 범위

본문 입력·명시적 저장·가상 성공/실패 상태의 명세만 포함한다. 저장 구현·제품 정책 확정·목록·검색·시안 제작은 제외한다.

## 변경 영향·인계

정책 결정 시 AC-001~004와 디자인의 EMPTY/EDITING/SAVING/SAVED/ERROR, 저장·이탈·재시도 행동을 재검토한다. 영향 작업은 TASK-002이며 제품화 작업은 아직 없다.
이번 하네스 시험은 요구사항의 마스킹된 불변 콘텐츠 스냅샷으로 인계한다. Git 커밋은 UNKNOWN이며 제품 실행 인계의 Git 버전 고정을 대신하지 않는다.
변경 이력은 Git으로 관리한다. 기획 산출물 검토 통과는 문서 연결 범위에만 적용한다.
