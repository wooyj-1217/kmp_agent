# 문서 인계 시험 입력

이 기능은 HARNESS_BUILD 시험 FEAT-001이며 실제 제품 기능이 아니다.
기존 [메모 요구사항](../memo/requirements.md)과 [디자인](../memo/design.md)을 입력으로 사용한다.
기획은 기존 수용 기준 4개와 UNKNOWN 정책·단계별 차단을 보존한 인계용 requirements.md를 작성한다.
디자인은 그 산출물을 받아 화면·상태·행동 연결을 design.md에 작성한다.
제품 정책을 결정하거나 제품 코드·시안·외부 도구를 만들지 않는다.
명세 작성, 시안 제작, 시각 검토는 별도 상태로 기록한다.
이번 시험의 완료는 문서 연결 검증에 한정하며 제품 준비 완료를 뜻하지 않는다.
