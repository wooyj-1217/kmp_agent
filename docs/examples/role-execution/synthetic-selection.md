# 합성 시험 선택 — 실제 사용자 승인 아님

P-001에 대응하는 대표 A/B를 실제 Chrome 1280×900에서 열고 캡처했다. B는 390×844에서도 가로 넘침 없음을 확인했다. 근거는 evidence/representative-A.jpg, representative-B.jpg, representative-B-mobile.jpg다. 이는 비교 화면 확인이며 최종 전체 상태 시각 검토 PASS가 아니다.

brief.md에 정의된 합성 대기·재개 시험 입력으로 **A**를 선택한다. A의 중앙 단일 열은 본문 입력에 집중하고 읽기 순서가 단순하다. 대안 B는 안내를 함께 볼 수 있으나 이번 단일 화면 예제에는 추가 열이 필수가 아니다. 실제 제품 방향 결정은 미정이다.

기존 대표 비교안과 tokens.css를 보존하고 선택 A의 최종 화면을 새 버전 파일로 추가한다. 재개 시 완료된 대표 비교·토큰·컴포넌트 작성을 반복하지 않는다. 최종 파일에는 실제 다섯 상태·가상 저장·오류·재시도·키보드 포커스를 연결하며 정책 UNKNOWN은 유지한다. 제출 시 동작·시각 검증은 NOT_RUN이며 별도 검토자가 실제 브라우저에서 확인한다. 최종 제출 JSON의 파일 경로는 기능 폴더 상대 경로 또는 정확한 기능 폴더 경로만 허용한다. 이전 비교안과 토큰·자원 파일도 제출 집합에 포함해 함께 보존한다.
